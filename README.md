# WAVR

Music Visualized Through Mood

WAVR is an interactive music visualizer built with React, Tailwind CSS, and Framer Motion. The application dynamically changes colors, animations, and visual effects based on the mood of the selected track.

## Features

* Dynamic mood-based themes
* Animated audio visualizer
* Glassmorphism UI
* Floating particle effects
* Responsive design
* Smooth Framer Motion animations

## Tech Stack

* React
* JavaScript
* Tailwind CSS
* Framer Motion
* Vite
* GitHub
* Vercel
